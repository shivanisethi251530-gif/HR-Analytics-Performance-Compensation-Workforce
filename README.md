# 📊 HR Analytics – Performance, Compensation & Workforce | CA2

This project was completed as part of my **Industry Classes CA2 assessment** and focuses on applying **Microsoft Excel, Power Query, and statistical analysis techniques** to an HR dataset containing 300 employee records.

The objective of the project was to analyse employee data related to compensation, experience, leave, job satisfaction, and performance while demonstrating practical skills in data cleaning, transformation, Excel functions, PivotTables, and statistical hypothesis testing.

## 🛠️ Tools & Skills Used

- Microsoft Excel
- Power Query
- Excel Functions & Formulas
- PivotTables
- Data Cleaning & Transformation
- Descriptive Statistics
- Hypothesis Testing
- One-Sample t-Test
- One-Sample z-Test
- Confidence Intervals
- HR Analytics

## 📌 Key Tasks Performed

- Cleaned and validated employee data using **Power Query**
- Checked Employee IDs for duplicates and identified missing/null values
- Corrected data types for dates, salaries, experience, ratings and other numerical fields
- Created an **Experience Band** using conditional logic
- Extracted numeric Employee Codes from Employee IDs using Power Query and Excel text functions
- Created employee joining-month information using Excel date functions
- Built a **PivotTable** to analyse employee count and average performance rating by joining month
- Conducted a **two-tailed one-sample t-test** to determine whether average employee salary differed significantly from ₹60,000
- Conducted a **one-tailed one-sample z-test** to analyse whether average employee leave was greater than 12 days
- Calculated a **95% confidence interval** for average employee job satisfaction
- Compared **pre-training and post-training performance** to assess whether employee performance appeared to improve

## 🎯 Learning Outcomes

This project strengthened my practical understanding of how **Excel and statistical techniques can be used for HR and business decision-making**. It provided hands-on experience in transforming raw data into structured analysis, applying hypothesis tests, interpreting statistical results, and presenting evidence-based HR insights.

The overall workflow followed:

**Raw HR Data → Data Cleaning → Transformation → Excel Analysis → Statistical Testing → Business Interpretation**
